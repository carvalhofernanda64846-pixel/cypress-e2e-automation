MÉTODO 1: Duplo clique no arquivo .bat (Mais Fácil)
─────────────────────────────────────────────────────
1. Dê duplo clique em: abrir-cypress.bat
2. O Cypress deve abrir automaticamente


MÉTODO 2: Git Bash (Recomendado)
─────────────────────────────────
1. Clique com botão direito na pasta "testes"
2. Selecione "Git Bash Here"
3. Digite: npm run cy:open
4. Pressione Enter


MÉTODO 3: PowerShell (se npm estiver funcionando)
───────────────────────────────────────────────────
1. Abra PowerShell na pasta do projeto
2. Digite: npm run cy:open
3. Pressione Enter

  SE NÃO FUNCIONAR: Use Git Bash (Método 2)
