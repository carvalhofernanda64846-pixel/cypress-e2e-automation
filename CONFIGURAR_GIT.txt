  CONFIGURAR GIT - Execute estes comandos no PowerShell
═══════════════════════════════════════════════════════════════

SUBSTITUA pelos seus dados:

& "C:\Program Files\Git\bin\git.exe" config --global user.name "Seu Nome"
& "C:\Program Files\Git\bin\git.exe" config --global user.email "seu-email@exemplo.com"

Exemplo:
& "C:\Program Files\Git\bin\git.exe" config --global user.name "João Silva"
& "C:\Program Files\Git\bin\git.exe" config --global user.email "joao@email.com"
